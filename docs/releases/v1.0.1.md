# Mixer Hub v1.0.1 — automatic LED sleep

**Install both the updated Windows app and firmware for this fix.**

## Downloads

- **MixerHub.exe** — Windows 10/11 x64 companion. Quit the old app from its tray
  menu before replacing it, then run this EXE. Existing profiles/settings are retained.
- **MixerHub-firmware-v1.0.1.zip** — extract it, keep `MixerHub.ino` and
  `startup_animation.h` together inside the `MixerHub` folder, and open the `.ino`
  in Arduino IDE. Select your matching classic Nano/bootloader/port, install
  Adafruit NeoPixel, then Verify and Upload. Quit the companion during flashing.
- **build-manifest.json** — version, source commit and SHA-256 checksums for the
  Windows executable and firmware ZIP.

## What changed

- The app sends a small heartbeat once per second while connected, including
  while its window is in the tray.
- Firmware turns the LEDs off when the heartbeat stops for five seconds, even
  if the PC keeps supplying USB power in sleep, hibernation or shutdown.
- Windows power notifications request an immediate blackout. The firmware timeout
  remains the fallback if Windows suspends or terminates the app before that write.
- The previous connection is retried on wake, with a bounded 30-second retry
  window while USB becomes available. Deliberate Disconnect is respected.
- Saved brightness, colours and profiles are retained; blackout does not save a
  zero-brightness preference or change local mute state. A board reset still
  resets volatile firmware state as before.
- The blue startup animation remains. After the five-second startup grace period,
  the mixer stays dark until the matching app connects and sends heartbeats.

**Compatibility:** the older EXE does not send heartbeats, so this firmware goes
dark after five seconds with that EXE. Upgrade both parts. The new EXE can send a
best-effort blackout to older firmware, but the reliable timeout requires reflashing.

The code was compiled for a classic ATmega328P Nano and regression-tested with
simulated serial/audio and power notifications. The builder reported successful
hardware testing. Suspend/reset timing can depend on the Nano variant, USB interface
and motherboard; firmware is not uploaded automatically by installing the EXE.

The EXE is unsigned. If SmartScreen flags an unrecognized app, verify that you
downloaded it from this repository and trust it before choosing More info → Run anyway.

Full setup and behaviour: [LED sleep guide](https://github.com/RyGuy06/mixer-hub/blob/main/firmware/POWER.md).
