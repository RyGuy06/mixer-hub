# Mixer Hub v1.1.0

Slider calibration and a tidier app for existing Mixer Hub hardware.

## What changed

- **Slider calibration:** record the real 0% and 100% positions of all four
  sliders and adjust the end dead zone. Settings are saved per mixer and restored
  on reconnect. Requires the matching calibration firmware.
- **Priority inside the main window:** edit fallback lists without opening a
  separate window.
- **Searchable app selection:** find running or remembered apps by friendly name
  or executable name, including games that are currently closed.
- **Resize improvements:** reduce repeated control redraws and apply monitor
  scaling after a drag finishes. Content holds its previous layout during resizing,
  then catches up after release.

## Install or update

1. Choose **Quit Mixer Hub** in the old app's tray menu. Clicking X only hides it.
2. Replace the old EXE with **MixerHub.exe** from this release and run it.
   Existing settings and profiles are retained. Windows 10/11 x64; no Python needed.
3. To enable calibration on older firmware, extract **MixerHub-firmware-v1.1.0.zip**
   and follow the [Arduino flashing guide](https://github.com/RyGuy06/mixer-hub/blob/main/firmware/README.md).
   Keep `MixerHub.ino`, `startup_animation.h` and `slider_calibration.h` together
   inside `MixerHub/`. This is one Arduino upload, not three separate uploads.
4. Connect, then follow the [slider calibration guide](https://github.com/RyGuy06/mixer-hub/blob/main/docs/CALIBRATION.md).

Ordinary mixing still works with v1.0.1 firmware; calibration needs the new
firmware. Blue startup and automatic LED sleep remain. **build-manifest.json**
contains SHA-256 checksums for the EXE and firmware ZIP.

Moving between displays with different scaling can still produce a noticeable
layout pause after dropping the window. The laptop/eGPU monitor combination has
not been verified end to end.

The EXE is unsigned. If SmartScreen warns, confirm the download came from this
repository and that you trust it before choosing **More info → Run anyway**, if offered.
