# PCB manufacturing files

One Mixer Hub requires both boards:

- **MainV2Gerbers.zip** — main PCB manufacturing files.
- **SliderV2Gerbers.zip** — slider PCB manufacturing files.

Upload each ZIP separately to your PCB manufacturer and order one of each board per mixer.

PCB specifications: two layers, 1.6 mm thickness.

“V2” identifies the PCB design revision; it is separate from the Mixer Hub product and software version.
